# 产品运行边界

本仓库是可独立构建和启动的 A7C II 模拟器产品。除了主机编译工具和常规依赖，外部输入仅为 ILCE-7CM2 2.01 ALLLANG `BODYDATA.DAT` 与固定版本 QEMU 11.1.2 源码归档。构建和运行不读取研究仓库、完整系统 dump 或历史运行目录。

入口为根目录 `start.sh`、`build-qemu.sh`，相机窗口和设备模型在 `runtime/analysis/`；所需固件资源从用户提供的 BODYDATA 校验并导入。产品会保留自己的虚拟卡和已支持的设置，原固件输入不改写。

当前能显示原厂 LCD、操作菜单和机身控制、使用虚拟卡；取景区域仍可能为黑色，拍照录像、完整设置持久化、USB 枚举与认证尚未全部完成。窗口显示不作为成片或完整硬件启动的证明。

完整镜像、WBI、原更新器及其临时观测继续在 [a7c2-re 研究仓库](https://github.com/SONY-FW/a7c2-re)维护。未接入产品的调研脚本和嵌套项目快照不随本产品分发，也不是启动前置条件。

当前 README 新图取自同一产品的新连续 LCD / 原 App32 常驻输入版本，显示原拍摄 HUD；固定官方包和源码 QEMU 输入未变，没有重绘原 LCD。该轮显式选择已有 `virtual-rom-v1`，没有真实无线。

连续显示已与输入队列分开，原 50ms 按压/释放和完整帧读回/摘要保持。真实 12 个窗口样本中位数 97.3ms，最大 121.1ms，严格所有样本小于 100ms 仍未通过。LCD 消费者实际读取 43,155 次、119 次像素内容改变，平均 119.91 次有效读取/秒；这不是原创画面变化 FPS。

同轮原首设按键进入原拍摄 HUD，但固定历史页序列的旧 checker 仍失败；人工 HUD 可见与 checker 通过分开记账。随后原 `pre_power_off` / `0x309` 黑帧出现，MENU 未恢复；本轮没有电源因子证据，不把旧轮 APO1 归因直接迁入。原 QMP quit/owner rc0/无信号退出、32 块跨通道卡摘要与 fsck0、用户原配置未变已核。

本轮核心八组并发回归全过。发布前另有八并发检查，唯一 host 失败来自旧 sender 测试替身，适配后的补验为 323 passed / 34 skipped / 89 subtests；旧失败与跳过范围保留。详见[连续 LCD 与原输入](2026-11-07-low-latency.md)和[脱敏验证收据](../../validation/product-low-latency-20261107.json)。

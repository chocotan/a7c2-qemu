# 产品运行边界

本仓库是可独立构建和启动的 A7C II 模拟器产品。除了主机编译工具和常规依赖，外部输入仅为 ILCE-7CM2 2.01 ALLLANG `BODYDATA.DAT` 与固定版本 QEMU 11.1.2 源码归档。构建和运行不读取研究仓库、完整系统 dump 或历史运行目录。

入口为根目录 `start.sh`、`build-qemu.sh`，相机窗口和设备模型在 `runtime/analysis/`；所需固件资源从用户提供的 BODYDATA 校验并导入。产品会保留自己的虚拟卡和已支持的设置，原固件输入不改写。

当前能显示原厂 LCD、操作菜单和机身控制、使用虚拟卡；取景区域仍可能为黑色，拍照录像、完整设置持久化、USB 枚举与认证尚未全部完成。窗口显示不作为成片或完整硬件启动的证明。

完整镜像、WBI、原更新器及其临时观测继续在 [a7c2-re 研究仓库](https://github.com/SONY-FW/a7c2-re)维护。未接入产品的调研脚本和嵌套项目快照不随本产品分发，也不是启动前置条件。

当前 README 新图取自已发布代码的实际窗口，使用固定官方包和本次从源码构建的 QEMU；没有重绘原 LCD 或使用历史截图替代。

# 普通 AP USB 功能选择与 MSC：实际边界（2026-11-10）

## 结论

本轮已恢复到原 AP 的 USB 初始化、真实功能选择页和“正在连接至海量存储器…”原 LCD。**宿主枚举、MSC function 绑定、原 MSC DSO 消费和宿主块设备读回均未通过**；`ordinary_ap_usb_menu_route_verified=false`、`msc_storage_readback_verified=false`。

公开失败边界收据：`validation/usb-msc-frontier-20261110.json`，SHA-256 `a09408482e8c0dd34ab6fc4b61d7530955a59befb48560a71ecd5f14cf55ae5b`。它不把多轮局部进展拼成成功。

## 实际证明的链路

显式 `virtual-functional-sony-usb-device-v1` 与 `A7C2_USB_MSC=1` 下：

1. 原 `insmod_drv2` 的 `usb_portMonitor → usbg_sen → usb_extcmd` 均实际加载。`usb_extcmd.ko` 仅在显式 USB profile 按原 SHA `63554be9f7bf7cbba3d9de16ce3d8675e3b60a323be1fa92839fa9eec0caa8c2` 准入；其它未建模模块仍拒绝。
2. MSC IMDB 只恢复原 `libInfraUsbCmn.so` 与 `libUsbControl.so` 初始化。实际日志出现 `UsbControl_Init → usbif_initialize → openSvc`，openSvc 从 state1 到 state5、rc0，并打开原 event/otgcore/usbcore 设备。
3. VBUS 后出现原 `0x25b` 功能选择页。默认第0行是 USB 流式传输，MSC 是第1行；原 DOWN 的 press/release 与 LCD 行变化均核齐后才 ENTER。
4. ENTER 后再次实际 snapshot/display，得到“正在连接至海量存储器…”帧；fusb 内部 VBUS latch 和读回均为1。
5. 最新被动资源观测只看到原 `SVC_NOTIFY event=1`；没有原模块装载、storage create、`libInfraMscServer.so` 加载或可用 EP0 描述符。宿主控制面仍为 `gadget_not_ready`，未读取任何宿主机块设备。

## 关键根因

### IMDB bind 存在不等于实际消费

`bootin.sh` 使用 `LD_LIBRARY_PATH=/simulation:/usr/lib:/lib`。最初 MSC 候选只 bind 到 `/usr/lib/libIMDB.so`，但 `/simulation/libIMDB.so` 的默认副本优先被 im.elf 加载，mountinfo 因而造成过误导性表象。

修复后，`original_cold_boot.usb_imdb()` 将同一通过身份校验的候选同时映射为 `libIMDB-msc.so` 和实际优先命中的 `libIMDB.so`。默认 profile 不产生这些文件；host 测试核两名称指向同一候选及默认关闭。v13 的原始 UsbControl/openSvc 日志证明修复被消费。

### 不再使用固定语言方向或旧帧

验收驱动曾错误假设所有起始语言都能用“阿拉伯语起向下两次”的 helper。实际运行还出现日语、越南语等起始页。最终逐键读取当前可见目标/选中行，每次要求原输入边和 LCD 实际变化；目标不可见时才滚动。阿拉伯语右对齐标题另有独立、screen0x12d 绑定的内容分类与自包含位图回归。

MSC ENTER 后必须重新 snapshot/display；旧选择页截图不能代表后来的连接状态。

### 共享快照故障已单独修复

持久 `/tmp` 的固定 `.part` 在失败/冷启动后可导致 `open EEXIST`。`hosd_persist()` 改用 PID+原子 ticket 的唯一临时 inode，撞名跳过而不删除旧证据；写后全文 pread 和原子 rename 不变。该修复已在含旧 `.part` 的故障盘上实际恢复启动。

## 仍未完成

历史 sender 调查将 group0 停在原 `20a3` EE-capability 通知 future 等待，但**当前 MSC 与该等待的因果同一性尚未证明**。下一步应恢复/观察原通知生产者与 MSC 请求的真实提交链，不能手写20a3、清 inhibit、直接调用 START 或伪造 function/宿主枚举。

# 原固件提示音（WAV 导出）

这些 WAV 是**直接从原厂固件资源里切出来的字节**，不是合成、不是录制、不是我们自己造的音频：

- 索引：`/usr/share/avsystemsound/beeplist.txt`（原厂自带，给出 id / 文件名 / Size / FileOffset）；
- 数据：`SysSound.bin[FileOffset : FileOffset+Size]`，或该音自己的 `.bin`（两者逐字节相同）；
- 格式：切片开头 **128 字节前导**，其后是 **16-bit 小端 PCM**。

导出工具：`runtime/analysis/beep-extract.py`
复核命令：

```
python3 beep-extract.py --rate 48000 --beep 0x0000 --output 0000.wav --json
```

## 重要边界（不要误读）

1. **采样率没有存在索引里**。这里统一按 **48000 Hz** 导出；如果真机是 44100，则音高与时长会差 8.8%。
   这一项**尚未经固件证据确认**，听感只作参考。
2. `0001.wav`（`BEEP_ID_KA`）是 **0 帧**：它的切片正好 128 字节＝仅前导、无 PCM。
   这是原文如此，工具如实输出，不代表提取失败。
3. 这些文件证明“固件里确实带这些音”，**不**证明原固件在仿真里播放过它们。
   播放请求（`0x0203`）在设备模型里仍被拒绝，且只记录原始载荷。
